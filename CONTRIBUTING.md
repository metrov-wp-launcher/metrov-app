# How to help

This repo doesn't have the source code, so helping here means good bug reports and good ideas. That already helps me a lot.

## Before you open an issue

- **Update Metrov first.** The bug might already be fixed.
- **Search the issues**, open and closed. Closed ones sometimes have a workaround.
- **One issue per problem.** If you found three bugs, open three issues. It's much easier for me to track and close them one by one.

## Writing a good bug report

The more I can reproduce it, the faster I can fix it. Try to include:

- Metrov version (Settings > About)
- Phone model and Android version, plus the skin if it's not stock (One UI, MIUI/HyperOS, ColorOS, ...)
- Exact steps to make it happen
- What you expected and what actually happened
- A screenshot or screen recording

"The launcher crashes" is hard to fix. "It crashes when I resize the Photos tile to wide on a Pixel 8, Android 15" is easy.

## Writing a good feature request

- Tell me the problem, not only the solution. "I want X because I keep doing Y" helps me find the best way to do it.
- If it's something Windows Phone had, a screenshot or video of the original is gold.
- Check if it's already requested and 👍 it instead of making a new one. The number of 👍 is how I decide what to work on next.

## A few rules

- Be nice. To me and to other people here.
- English is best so everyone can follow, but if you're more comfortable in another language, go ahead, I'll figure it out.
- Please don't ask "when is this coming?" on every issue. I work on this alone in my spare time, so there are no dates. Updates come when they're ready.
- Don't post personal info like email, phone number or purchase receipts in public issues. Send those to me privately (see the README).

Thanks for helping 💙
