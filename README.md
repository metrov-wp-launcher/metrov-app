# 📱 Metrov: WP Launcher

Feedback, bug reports and feature requests for **Metrov: WP Launcher**, an Android launcher that brings back the tile-based look of Windows Phone.

> **Note:** This repo is only for feedback. The app's source code isn't here.

---

## 🙏 A quick heads up

Just so you know, Metrov is made by one person. That's me. I do the coding, the design, the testing, the Play Store stuff and the replies here, all in my free time.

I do read every bug report and feature request, I promise. But honestly, I'm pretty lazy about updating the tickets. So an issue might sit there with no label and no reply for a while, and then one day the fix just shows up in an update. Or I close a bunch of old ones all at once when I finally remember.

If your issue looks ignored, it probably isn't. Please be patient with me, and thanks for sticking around 💙

---

## 📌 What is Metrov?

A launcher for people who miss the Metro UI. Some of the things it has:

- Live tiles in different sizes that you can arrange however you like
- Action center with notifications
- Smooth Metro style animations
- Accent colors, themes and many languages
- And a lot more, with new stuff in most updates

## 🐞 Found a bug?

1. Search the [open issues](https://github.com/metrov-wp-launcher/metrov-app/issues) first. If someone already reported it, add a 👍 or a comment with your phone model.
2. If not, [open a bug report](https://github.com/metrov-wp-launcher/metrov-app/issues/new?template=bug_report.yml).
3. Fill in your Metrov version, phone and Android version. A screen recording helps more than anything.

## 💡 Have an idea?

1. Look through the [existing requests](https://github.com/metrov-wp-launcher/metrov-app/issues?q=is%3Aissue+label%3Aenhancement). If it's there, 👍 it. I use the votes to decide what to build next.
2. If it's new, [open a feature request](https://github.com/metrov-wp-launcher/metrov-app/issues/new?template=feature_request.yml).

## ❓ Just a question?

The [Discord](https://discord.gg/HgN3HdQpxT) or [r/metrovlauncher](https://www.reddit.com/r/metrovlauncher/) is usually the fastest way. Other users often answer before I do. You can also [ask here](https://github.com/metrov-wp-launcher/metrov-app/issues/new?template=question.yml).

More details on writing a good report are in [CONTRIBUTING.md](CONTRIBUTING.md).

---

## 🏷️ What the labels mean

| Label | Meaning |
| --- | --- |
| `bug` | Something is broken |
| `enhancement` | A feature request |
| `question` | Someone needs help |
| `duplicate` | Already reported somewhere else |
| `wontfix` | I've decided not to do it, sorry |

If an issue has no label, it just means I haven't gotten to it yet. I still saw it.
